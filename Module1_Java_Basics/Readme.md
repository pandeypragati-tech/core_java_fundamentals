# Module 1 — Java Basics

This module covers the fundamental concepts required to start programming in Java.

## Concepts Covered

* Introduction to Java
* First Java Program
* Variables
* Constants
* Data Types
* Literals
* Type Casting

## Programs

| Program                | Concept                     |
| ---------------------- | --------------------------- |
| `HelloJava.java`       | First Java program          |
| `VariablesDemo.java`   | Variables                   |
| `ConstantsDemo.java`   | Constants using `final`     |
| `DataTypesDemo.java`   | Java data types             |
| `LiteralsDemo.java`    | Java literals               |
| `TypeCastingDemo.java` | Type conversion and casting |

## Learning Outcome

After completing this module, you should be able to:

* Understand the basic structure of a Java program.
* Create and run a simple Java program.
* Declare and initialize variables.
* Use different primitive data types.
* Define constants using `final`.
* Understand literals.
* Perform basic type conversion and type casting.
