# Module 10 — Mini Projects

This module contains small Java-based mini projects that combine the concepts learned throughout the **Core Java Fundamentals** repository.

The projects are designed to strengthen problem-solving skills and demonstrate how individual Java concepts can be combined to create practical console-based applications.

---

## 📌 Concepts Used

These projects use concepts from previous modules:

* Variables
* Data Types
* Operators
* Input and Output
* `Scanner`
* Type Casting
* Conditional Statements
* `if-else`
* `else-if`
* `switch`
* Loops
* `break`
* `continue`
* Methods
* Arrays
* Strings
* Basic Random Number Generation

# 1. Calculator

A basic calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division
* Remainder

### Concepts

* `Scanner`
* `switch`
* Operators
* Input/output

---

# 2. Number Guessing Game

The computer generates a random number and the user tries to guess it.

The program provides hints:

* Too high
* Too low
* Correct

### Concepts

* `Random`
* `while`
* `if-else`
* User input

---

# 3. Simple ATM

A simple ATM simulation supporting:

* Check balance
* Deposit money
* Withdraw money
* Exit

### Concepts

* `switch`
* `while`
* Conditions
* Methods
* User input

---

# 4. Student Grade System

Takes marks and calculates the student's grade.

Example grading:

```text
90 - 100 → A
75 - 89  → B
60 - 74  → C
40 - 59  → D
Below 40 → F
```

---

# 5. Electricity Bill Calculator

Calculates an electricity bill based on units consumed.

Example slabs:

```text
0 - 100 units   → ₹5 per unit
101 - 200       → ₹7 per unit
Above 200       → ₹10 per unit
```

---

# 6. Shopping Bill

Takes item prices and quantities and calculates:

* Total amount
* Discount
* Final bill

---

# 7. Temperature Converter

Converts:

* Celsius → Fahrenheit
* Fahrenheit → Celsius

Formula:

```text
F = (C × 9 / 5) + 32

C = (F - 32) × 5 / 9
```

---

# 8. Unit Converter

Provides simple conversions such as:

* Kilometer → Meter
* Meter → Kilometer
* Kilogram → Gram
* Gram → Kilogram

---

# 9. Rock Paper Scissors

A console-based Rock Paper Scissors game.

The computer randomly selects:

```text
Rock
Paper
Scissors
```

The user selects one option and the winner is determined using conditions.

---

# 10. Quiz Game

A simple multiple-choice quiz.

The program:

1. Displays questions.
2. Takes the user's answer.
3. Checks the answer.
4. Calculates the score.
5. Displays the final result.

---

# 11. Password Checker

Checks basic password requirements.

The password should contain:

* Minimum 8 characters
* At least one digit
* At least one uppercase letter
* At least one lowercase letter

---

# 12. Number Utility

A menu-driven number utility that can perform:

* Even/Odd check
* Prime check
* Factorial
* Reverse number
* Palindrome check

This project combines several programs from the loops and methods modules.

---

# 13. Student Result System

Takes marks of multiple subjects using an array and calculates:

* Total marks
* Average
* Highest mark
* Lowest mark
* Grade

This project combines:

* Arrays
* Loops
* Methods
* Conditions
* Input/output

# 🎯 Learning Outcomes

After completing these projects, you should be able to:

* Combine multiple Java concepts.
* Build console-based applications.
* Use methods to organize program logic.
* Work with user input.
* Apply conditions and loops to real problems.
* Work with arrays and Strings.
* Improve problem-solving skills.
* Write small Java applications independently.
