## JDK, JRE and JVM

### JDK

JDK stands for Java Development Kit. It provides the tools required to develop, compile, debug, and run Java applications.

### JRE

JRE stands for Java Runtime Environment. It provides the environment and libraries required to run Java applications.

### JVM

JVM stands for Java Virtual Machine. It executes Java bytecode and provides the runtime environment for Java programs.

### Easy Way to Remember

```text
JDK → Develop
JRE → Run
JVM → Execute
```

## Java Program Execution

```text
Java Source Code (.java)
          ↓
       javac
          ↓
Bytecode (.class)
          ↓
         JVM
          ↓
        Output
```

Java source code is compiled by the Java compiler into bytecode. The JVM then executes the bytecode.

## Algorithm

An algorithm is a finite sequence of clear and well-defined steps used to solve a particular problem.

### Example: Addition of Two Numbers

1. Start
2. Accept two numbers A and B
3. Calculate `Sum = A + B`
4. Display Sum
5. Stop

## Flowchart

A flowchart is a graphical representation of an algorithm using standard symbols and arrows to show the flow of a solution.

### Common Flowchart Symbols

| Symbol        | Purpose        |
| ------------- | -------------- |
| Oval          | Start / Stop   |
| Parallelogram | Input / Output |
| Rectangle     | Process        |
| Diamond       | Decision       |
| Arrow         | Flow direction |
